# Security Policy

## Sample status

Content in this repository is community-provided sample material intended for
learning and adaptation. Samples are not Microsoft products and must not be
used in production without an appropriate security, privacy, compliance, and
governance review by your organization.

## Reporting a security concern

**Do not report suspected vulnerabilities, credentials, personal data,
customer content, or exploit details in a public GitHub issue.**

For a potentially sensitive security issue, email
[secure@microsoft.com](mailto:secure@microsoft.com) with:

- the affected repository, sample, file, branch, or commit;
- the type and potential impact of the issue;
- non-sensitive reproduction steps and required configuration;
- proof-of-concept details, if appropriate;
- a safe way to contact you for follow-up.

For non-sensitive hardening suggestions that do not disclose a vulnerability,
you can use the repository's
[issue forms](https://github.com/pnp/copilot-prompts/issues/new/choose).

The community will triage sample-specific reports on a best-effort basis. For
vulnerabilities in Microsoft products or services, use the
[Microsoft Security Response Center](https://aka.ms/security.md/msrc/create-report).
