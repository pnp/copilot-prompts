# Validation evidence

Date: October 13, 2026. Status: draft contribution with offline validation; real-export and host validation pending.

## Executed

- `python3 -m unittest discover -s tests -v`: 19 tests passed.
- Skill-creator frontmatter validation passed using the installed Azure CLI Python runtime, which supplies PyYAML. The checker itself requires only the Python standard library.
- Incomplete synthetic settings: BLOCKED with EMPTY_CONNECTION and CONNECTOR_MISMATCH; EMPTY_VALUE and MISSING_MAPPING require review.
- Complete synthetic settings: STATIC_COVERAGE_COMPLETE with five target verification items still unverified.
- Tests cover duplicate logical/schema names, case-insensitive comparison, extra mappings, malformed roots/sections/entries, missing connections, missing and blank variables, nonstring values, placeholder connections, invalid template connectors, empty inventories, CLI exit statuses, duplicate JSON keys, and suppression of configuration values in both report formats and invalid-input errors.
- Example reports were generated by the actual CLI, not manually authored.
- Sample PNG captured from a browser rendering of actual synthetic-fixture checker output; visual layout inspected.
- Gallery metadata, README tracker identity, local links, and skill schema checked before submission.

A test-helper bug initially substituted the good fixture when testing a null JSON root. The test was corrected to call the checker directly; null roots correctly report INVALID_ROOT.

## Not yet verified

- Real PAC-generated template against an exported solution.
- Skill-following behavior and automatic activation in GitHub Copilot.
- Target connection existence/access, effective target values, dependencies, permissions, policy, licenses, gateway, import, activation, or application smoke tests.
- GitHub Copilot execution screenshot. The included PNG is a rendering of actual checker output using synthetic fixtures, not a host activation demonstration.

The JSON fixtures are synthetic examples following Microsoft's documented settings contract. They are not PAC exports or importable solutions. No environment authentication, configuration changes, import, or deployment was performed.

## Suggested next trial

Use a nonproduction solution with at least one environment variable and connection reference. Generate the template from the exact exported ZIP; review a sanitized target settings file through GitHub Copilot. Compare reported findings with known missing/incorrect mappings. Include a valid existing target/default variable case to detect false positives. Keep any configuration values and identifiers private. A live sandbox import requires separate authorization.
